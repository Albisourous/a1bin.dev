accessibility

a1bin.dev — the site that looks like an ide

target: WCAG 2.2 level AA. status: partially conformant — last reviewed november 2026.

what works

  • every control is keyboard reachable — explorer, tabs, editor, chat, terminal, status bar
  • text is real text. it selects, zooms, and reads through a screen reader
  • two themes with checked contrast — the status-bar toggle remembers your pick
  • animation only runs when your system allows it (prefers-reduced-motion)
  • icon-only buttons carry aria-labels, and the panels are named landmarks

known limitations

  • the snowboard game is ascii art — a wall of characters with no screen-reader story
  • the graph view is a visual map. every link in it is also a plain file in the explorer
  • the resume is a pdf. the text extracts fine, but it's still a pdf
  • edits you make in the editor are session-only and aren't announced

spot something broken? email me — accessibility bugs get fixed first.
