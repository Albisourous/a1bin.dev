# a1bin.dev — Design Document

> Personal site for Albin Shrestha, presented as a corrupted `.bin` file
> opened in Windows-classic Notepad. The site *is* the file.

## 1. Concept

**"My personal site is the printable strings of a corrupted binary."**

You know `strings(1)` — the unix tool that pulls human-readable text out of a
binary? This site inverts it. The whole page renders as one giant Notepad
window displaying `a1.bin`: a wall of mojibake (à¹â°êý, ±²³, letter runs
like `IIJJGGFFEEDDCCBBAA`, `PK\x03\x04` zip magic) with the actual content —
name, bio, links — embedded as readable *strings* inside the noise, exactly
like real binary dumps where fragments of text leak through.

The noise isn't decoration. It **is** the design system.

### Why it's unique

- Most retro sites fake a terminal. This fakes a *mistake* — a binary opened
  in the wrong program. That specific texture is instantly recognizable to
  anyone who has ever done it, and nobody else's site looks like it.
- The mojibake is generated by a seeded PRNG with weighted character tables
  sampled from real corrupted dumps — every visit shows the same "file"
  (deterministic), but it feels organic.
- UI chrome is functional: menus do things, the status bar tracks your
  cursor, word wrap actually toggles. The joke goes all the way down.

## 2. Art Direction

### Reference

- Notepad on Windows XP/2000: white document, `Lucida Console` 10pt,
  Tahoma chrome, `#ECE9D8` window face, blue gradient title bar,
  `Ln 1, Col 1` status bar.
- Hex editors (HxD/Bitberry): offset column, 16 bytes per row, ASCII gutter.
- Real corrupted dumps: UTF-8 bytes decoded as CP1252 — the *exact* texture
  in the reference screenshot.
- *All About Lily Chou-Chou* (2001, Shunji Iwai): the film's BBS
  intertitles — full-bleed flat color fields with pale, low-contrast text
  blocks floating in them. Quiet, dissociative, text-as-atmosphere.

### Desktop layer (Frutiger Aero)

The Notepad window doesn't float on a flat page — it sits on a **desktop**.
The wallpaper is a pure-CSS Frutiger Aero composition: glossy aurora sky
gradient, layered mountain/hill silhouettes, a soft glass sheen. No image
assets — gradients + SVG-ish CSS shapes, all token-driven.

- Sky: `aero-sky-a → aero-sky-b` vertical, faint aurora band.
- Mountains: 2 layered silhouettes (repeating linear-gradient ridge or
  inline SVG data-URI), `aero-mtn` at different alphas.
- Meadow: bottom third, `aero-field-a → aero-field-b` radial sheen,
  glossy highlight ellipse (the Aero "wet gloss" look).
- The window casts a soft drop shadow onto the wallpaper; page `::before`
  supplies the scene, content windows layer above.

### Intertitle layer (Lily Chou-Chou)

The film's BBS screens give us the site's *transitional grammar*: wherever
the Notepad fiction breaks — initial load, phase-2 view switches, section
breathers — we cut to a flat color field with low-contrast ghost text
instead of animating UI.

- **Boot intertitle:** on first load, full-viewport `intertitle-bg` field,
  pale glyph blocks typed in like forum posts (the film's "Lily Philia"
  BBS text), then a hard cut to the Notepad window. No fade, no easing —
  the film cuts.
- **Section breathers (optional, P1):** scrolling past N lines of noise can
  yield a thin full-width intertitle strip — flat field, ghost text —
  before the file resumes.
- Ghost text is the same weighted mojibake charset, just rendered at
  `intertitle-ink` on `intertitle-bg`: texture stays consistent, only the
  contrast changes.

### Type

- **Document:** `"Lucida Console", "Courier New", ui-monospace, monospace` —
  15px/1.35 body. All document text is monospace, no exceptions.
- **Chrome (menus, title, status):** `Tahoma, "MS Sans Serif", system-ui,
  sans-serif` — 11px. Not the system font Notepad actually used on XP
  (MS Sans Serif is non-scalable bitmap); Tahoma is the metric-compatible,
  legally shippable equivalent.
- No webfonts shipped in v1 — OS stacks get us 95% there with zero deps.

### Texture rules

- Mojibake lines are **long** (200+ chars), so Word Wrap OFF gives a
  horizontal scrollbar — matches the reference.
- Character mix, weighted: ~55% high-latin mojibake glyphs, ~20% ASCII
  symbol noise, ~15% ascending/descending letter runs
  (`..ZZYYXXWVUTSRQPONMLK..`), ~10% ASCII word fragments (`bcdefgh`,
  `aceg`).
- 2–4 readable "strings" per screen of noise. Sparse enough to hunt for,
  dense enough to find.
- NULL padding as runs of `•` or `····` — reads as `00 00 00` regions.

## 3. Information Architecture

One route. One window. Content is ordered like a binary's layout:

```
┌─ title bar ───── a1.bin - Notepad ────────── _ ▢ ✕ ┐
│ File  Edit  Format  View  Help                        │
│ A1BINDATA  |  v2.0.4                    header record │
│ <mojibake>                                            │
│ <mojibake>   albin shrestha — seattle, wa   [STRING]  │
│ <mojibake>                                            │
│ <mojibake>   building software that ...     [STRING]  │
│ <mojibake>                                            │
│           § strings                                   │
│ <mojibake>   github.com/Albisourous         [STRING]  │
│ <mojibake>   x.com/albinshr                 [STRING]  │
│ <mojibake>                                            │
│ <mojibake>              EOF record: ■                 │
│                                          scrollbar →  │
└─ status bar ────────────────  Ln 12, Col 47 ──────────┘
```

- **Header record** — `A1BINDATA | v2.0.4` (mirrors `MEAS3102DATA` in the
  reference). The "magic bytes" of the file.
- **Strings section** — a `§ strings`-style marker, then the link strings.
  This is the site's nav: there's no navbar, links live inside the file.
- All copy lives in `src/content/site.js`. The doc generator splices it
  into the noise — the document is *computed*, not authored.

## 4. Interactions

Everything functional, nothing decorative-only:

| Element          | Behavior                                                        |
|------------------|-----------------------------------------------------------------|
| **Strings**      | Scramble-in on first paint: chars cycle through mojibake pool,  |
|                  | resolve left→right. Re-scramble on hover. Click = link.         |
| **Caret**        | Clicking in the document moves a blinking block caret (Notepad  |
|                  | behavior). `Ln`, `Col` in the status bar track it.              |
| **Status bar**   | `Ln N, Col N` live. Mouse hover also updates Col like real      |
|                  | Notepad selection.                                              |
| **Format menu**  | `Word Wrap ✓/□` — toggles `white-space: pre ↔ pre-wrap`;        |
|                  | horizontal scrollbar appears/disappears. Real behavior.         |
|                  | `Font…` — phase 2 (fake dialog).                                |
| **Edit menu**    | `Copy` copies page URL. `Select All` selects the document.      |
|                  | `Time/Date` inserts current timestamp at caret — real Notepad   |
|                  | menu items, real behavior.                                      |
| **File menu**    | `Save As…` downloads the document as `a1.bin` (real bytes).  |
|                  | `Page Setup…`, `Print…` → stub dialogs phase 2. `Exit` → closes |
|                  | window or shows fake "cannot close" phase 2.                    |
| **View menu**    | `Status Bar ✓` toggles it. Phase 2: `Hex View` switches the     |
|                  | document into a hex-dump rendering of its own bytes (the        |
|                  | second reference screenshot — same site, other lens).           |
| **Help menu**    | `About Notepad` → phase 2 dialog (about section).               |
| **Title bar**    | `_` minimizes to taskbar strip, `✕` shows XP "Are you sure?"—   |
|                  | phase 2. Draggable window — phase 2.                            |
| **Selection**    | Real text selection everywhere; styled `#316AC5` on white.      |

Motion rules: scramble ≤ 400ms, caret blink 530ms (real caret blink rate),
no easing on chrome (system UI doesn't ease), `prefers-reduced-motion`
skips scramble and blink.

**Stack:** Vite + React 18, **plain JavaScript** (no TS — matches what you
know), **SCSS** for mixins + tokens, CSS custom properties emitted at
`:root` so tokens are also usable at runtime.

### Boundaries that keep it modifiable

- **Copy:** never in components — always `content/site.js`. Change bio in
  one place.
- **Look:** never raw values in components — always `tokens` + `mixins`.
  Recolor = edit `_colors.scss`.
- **Texture:** noise generation is pure (`seed → document model`), so the
  doc is testable and deterministic. Same seed, same file, every visit.
- **Components:** chrome (`window/`) vs content (`document/`) vs logic
  (`lib/`). No cross-imports except downward.

## 6. Content Model

`content/site.js` shape:

```js
export const SITE = {
  file: { name: "a1.bin", version: "v2.0.4", magic: "A1BINDATA" },
  strings: [
    { id: "name",   text: "albin shrestha — seattle, wa" },
    { id: "bio",    text: "building software that …" },       // TBD copy
    { id: "github", text: "github.com/Albisourous",
      href: "https://github.com/Albisourous" },
    { id: "x",      text: "x.com/albinshr",
      href: "https://x.com/albinshr" },
    // add/edit links here — everything else adapts
  ],
  menus: { /* labels + accelerators */ },

```

Noise density, line width, and charset weights are **constants** in
`lib/charset.js` — tunable like any other token.

## 7. Phases

**P0 — minimal working site (this build)**
Vite+React scaffold · tokens/mixins/base · boot intertitle (flat field,
ghost text typed in, hard cut to window) · Window chrome (title, menu
bar, scrollbars, status bar) · deterministic mojibake document · strings
with scramble-in + hover re-scramble + links · caret + Ln/Col tracking ·
Word Wrap toggle · Edit>Copy / Edit>Select All / Insert Time-Date ·
favicon · README.

**P1 — chrome comes alive**
File>Save As (downloads real `a1.bin`) · View>Status Bar toggle ·
About/Properties dialogs · draggable window + minimize-to-taskbar strip.

**P2 — second lens + deploy**
View>Hex View (document renders as hex dump of itself) · sound on open? —
no · GitHub Pages/Cloudflare deploy + `CNAME` for a1bin.dev · OG image =
the mojibake window itself (screenshot the page).

Out of scope for now: blog, dark mode (the joke needs the white Notepad),
mobile app chrome (degrades to simple stacked window on small screens).

## 8. Accessibility & Quality

- Document has `role="document"`, noise is `aria-hidden`, strings are real
  text in the accessibility tree — screen readers get the strings, not the
  corruption.
- `prefers-reduced-motion`: no scramble, no blink.
- Menus: full keyboard nav (arrows, Esc), real `menu`/`menuitem` semantics.
- Contrast: ink on paper is 21:1; dim glyphs only ever decorative.
- Test surface: pure doc generator → unit-test snapshot; scramble →
  deterministic under fixed seed.
